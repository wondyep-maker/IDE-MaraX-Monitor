# Lelit MaraX (PL62X) Smart Monitor & Mobile Hub - LilyGO T-Display-S3

专为 **Lelit Mara X (PL62X)** 意式半自动咖啡机与 **LilyGO T-Display-S3 (ESP32-S3, 320×170 8-bit 并口 ST7789)** 开发板打造的高刷双缓冲智能显示屏与手机互联中控系统（OS V2.1）。

---

## 核心特性

1. **8-Bit 并口双缓冲零闪烁渲染 (`Arduino_GFX_Library`)**
   - 针对 T-Display-S3 的 8 位并行 i8080 总线 (`Arduino_ESP32LCD8` + `Arduino_Canvas`) 深度优化，支持 25 FPS 全屏零闪烁刷新。
   - **正统开机画面**：左侧展示 **Lelit Mara X (PL62X)** 机身图像，右侧展示无白边的 Lelit 红底胶囊 Logo。
2. **真实 Gicar 6-Pin 串口 + 智能热力学仿真双擎自动切换**
   - 实时解析 Gicar 主板 `9600 baud` 串口数据帧（如 `C1.09,124,124,093,056,1,0`），自动识别 `C`（咖啡优先）与 `V`（蒸汽优先）模式、蒸汽锅炉实际/目标温度、HX 热交换器冲煮水温、Steam Boost 增压倒计时及加热器状态。
   - 支持 `GPIO 3` 外接 Ulka 振动泵干簧管传感器自动触发萃取秒表。
   - 未连接咖啡机时自动运行高拟真热力学与水力仿真模式 (`SIM`)，一旦收到真实串口数据帧自动无缝切换为硬件直读模式 (`RAW`)。
3. **双路压力 (Dual-Manometer) 实时解算与传感监测**
   - **蒸汽锅炉压力 (`0.00 ~ 3.00 bar`)**：直接基于 Gicar 串口输出的蒸汽锅炉实时温度，通过 **Antoine 饱和水蒸气热力学方程** 精确解算表压（如 `124°C = 1.25 bar`，`134°C = 2.05 bar`），无需破坏锅炉加装传感器即可在主界面与手机端直读。
   - **冲煮水泵压力 (`0.0 ~ 12.0 bar`)**：
     - **硬件传感器直读**：支持在 `GPIO 1` (`PIN_PRESSURE_ADC`) 接入 G1/4 模拟水压变送器（`0.5V ~ 4.5V` 对应 `0 ~ 16 bar`），检测到传感器电压时自动显示真实水压。
     - **E61 + OPV 物理水力模型**：未接水压传感器时，在水泵启动后按照 Mara X 静音振动泵 + E61 机械升压腔 (`E61 MECHANICAL RAMP`) + OPV 泄压阀 (`9.2 bar`) 特性实时展示建压与恒压轨迹。
4. **过热放水降温提醒 (`FLUSH!` Advisor)**
   - 当待机或蒸汽增压后 HX 水温超过 `96.0°C` 时，顶部状态栏与卡片边框自动高频红黄闪烁 `FLUSH!`，提醒先空放水 3 秒降温再扣柄萃取；`91.0 ~ 95.5°C` 黄金冲煮区间显示绿色 `READY`。
5. **蓝牙称重流速联动 (`g/s`) & 50 杯盲碗反冲洗保养提醒**
   - 萃取界面同屏显示 **秒表 (`s`) + 实时液重 (`g`) + 流速 (`g/s`) + 冲煮水压条 (`0~12 bar`)**，达到目标粉液比（如 `18g 粉 ➔ 36g 液`）全屏顶栏变绿提示压下 E61 手柄。
   - 利用 ESP32 `Preferences (NVS)` 闪存掉电保存历史总杯数，每满 50 杯自动提示盲碗反冲洗清洁 (`BACKFLUSH CLEAN DUE!`)。
6. **免 App 手机 Web 掌上中控台 (`http://marax.local`) + BLE 蓝牙服务 (`MaraX-BLE`)**
   - 板载响应式暗黑风手机网页中控，连入同一 Wi-Fi 或连接开发板热点 `MaraX-Monitor`（密码 `12345678`），手机浏览器访问 `http://marax.local` 或 `http://192.168.4.1` 即可实时监控双温双压并远程操控。

## 硬件接线简表 (LilyGO T-Display-S3)

| 功能模块 | T-Display-S3 引脚 | 连接目标 |
| :--- | :--- | :--- |
| **Gicar 串口数据接收 (RX)** | `GPIO 18` | Gicar 6-Pin 接口第 2 脚 (TX, 从靠近外壁侧往内数) |
| **系统共地 (GND)** | `GND` | Gicar 6-Pin 接口第 4 脚 (GND) |
| **振动泵干簧管传感器** | `GPIO 3` (内部上拉) | 干簧管一端（另一端接 `GND`，贴于红色 Ulka 振动泵外壳） |
| **可选水压传感器 (ADC)** | `GPIO 1` | 0~16 bar 模拟压力变送器信号线（分压至 0~3.3V） |
| **可选远程开机继电器** | `GPIO 2` | 继电器控制端（并联咖啡机电源开关） |

## 板端按键操作指南

- **上按键 (`TOP / GPIO 14`)**：
  - **短按**：循环切换 **第 1 页（双温双压 + 实时曲线仪表盘）** ➔ **第 3 页（含峰值水压的历史记录与保养）** ➔ **第 4 页（手机 Wi-Fi / BLE 互联中心）**。
  - **长按 (0.7 秒)**：在 **仿真演示模式 (`SIM`)** 与 **真实串口模式 (`RAW`)** 之间切换。
- **下按键 (`BOT / GPIO 0`)**：
  - **第 1 页短按**：切换目标粉液比（`1:1.8` / `1:2.0` / `1:2.2` / `1:2.5`）并给电子秤去皮。
  - **任意页长按 (0.5 秒)**：触发/停止萃取计时（自动进入 **第 2 页**），松开或再次短按停止萃取并计入历史。
  - **第 3 页长按**：重置 50 杯盲碗反冲洗保养计数器。
  - **第 4 页短按**：切换 `GPIO 2` 咖啡机远程电源继电器开关。
